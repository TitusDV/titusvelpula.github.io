AI · In production · Celtine Ltd

Customer-service agent system

Enquiries used to need staff to check several business systems before replying. The agent classifies each enquiry, gathers the conversation context and retrieves order and shipping information to prepare a response, or escalates to staff.

n8n · JavaScript · Claude and OpenAI APIs · business rules · structured output validation

What I learned from real cases

  • Partial shipments can sit under variations of the original order number, so I added lookups for separate dispatches.
  • I investigate failed runs and review generated replies to improve prompts, routing and error handling.
  • Prompts stay model-agnostic, so the provider can be swapped without a rewrite.

Telecare RAG Chatbot

Monitoring staff need fast, correct answers about alarm types, triage and escalation. This assistant answers from a process document and says when the documents don't cover a question, instead of guessing.

Source document (PDF) Code on request
01 IngestScrape the portfolio page with BeautifulSoup and Selenium, download the PDF, extract text with PyMuPDF.
02 ChunkRecursive character splitting, with an LLM-driven agentic chunker built for comparison.
03 RetrieveEnsemble of BM25 keyword search and MiniLM sentence embeddings.
04 AnswerA grounded prompt to a local Llama 3 through Ollama, or an OpenAI model, behind a Gradio UI.

Stack

Python · LangChain · rank-bm25 · sentence-transformers · DocArray · Ollama · OpenAI · Gradio

Next steps

Semantic chunking, a persistent vector store, and evaluating each chunking method on a question set.

Plato's Pizzeria Sales Analysis

A year of orders analysed for the owners: a sales forecast for the next quarter, busiest hours, and which table sizes and pizzas earn the most.

  • Tables of 1 to 4 people brought in about 86% of revenue ($702,852).
  • Two-person tables earned the most, though solo tables were most frequent.
  • Recommended dropping XL and XXL Greek pizza and stocking the four best sellers.
